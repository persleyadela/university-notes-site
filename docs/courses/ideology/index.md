# 思政类


其实很多课程都没有什么印象了，大部分课程如果闭卷那就考前2天背书，开卷就无所谓了；个人把思政的选修必修全上下来，发现给分好像都差不多（就是正态分布最中间那坨区域），当然自己属于那种思政课程上并没有特别花心思的一类，经常啃高中政治选考的老本行。

比较推荐的是赵文心老师（我那时候上的她的“中国近代史纲要”，89/4.5，记得还会教我们怎么去写这类论文，当时她好像还是新老师），还有包大为老师（上的他的“马克思主义原理”，89/4.5，老师人还挺幽默的，听他的课很有意思，我应该怎么形容呢——他的课属于那种让人很有欲望听下去的，我愿称之为“有嚼劲的课”🤣；而且也比较亲民，有一次好像是学在浙大上面有道选择题有问题，他手动给我把分加上去了）都是讲课认真清楚，有自己风格的那类老师。

根据周围同学以及校友圈听到和看到的反馈，感觉思政类的课的给分貌似属于“选择大于努力”的一类，有些老师给分整体会好点。不过我基本上都是按照预置课表来上的，唯一不同的是提前上了“毛泽东思想和中国特色社会主义理论体系概论”。

个人建议的话，如果高中有选政治/历史，可以提前上闭卷考的“马原”和“毛概”这些，应该都还有高中背书的残留记忆，考试会更加得心应手些——就类似于自然情况下在高中刚毕业那会儿的英语水平是人生巅峰一样（认真脸.jpg）。不过也要综合考虑自己课业是不是忙得过来，选择是否提前学习这些内容，无非是先苦后甜和先甜后苦的区别。
