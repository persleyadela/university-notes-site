# 通核

本人上的通识核心课程是“二十世纪法国知识分子”，2024-2025春夏学期的，89/4.5，一开始是上大班课，后面都是助教老师来上的小班课，每小组一学期好像是汇报两次，不强制要求回答问题（本人也是一学期下来没有发言过一次的选手），期中的时候需要交读书笔记；考试是开卷考，整体感受还是挺轻松的一门课，唯一缺点可能是太难选上了，自己上的时候看到有人在第一次课上给老师递补选课程的申请纸条，好像也成功了，吕一民老师人听说挺好的。


# 美育

本人上的美育类课程上“打开艺术之门——装饰画”，2025-2026秋冬学期郑林风老师的，88/4.2，老师说这门课第一次开；课上到也不是教怎么画画的，只是每次课有不同的主题然后给我们讲不同画的历史还有怎么去欣赏优秀画（或者说某些画为什么优秀）之类的，主要是在培养审美吧；晚上三节课，一般都会留一节课给大家自己画画。本人纯画画手残党，但是老师看着我的“一年级画作”并不嫌弃，只是耐心地仔细地看了看提了些建议；每周课一次画画作业，期中/期末各交一次；最后两三周比较轻松，ai作画，老师会讲有哪些ai可以用，怎么给提示词之类的。

说实话，这课对我来说有点煎熬。人对自己不擅长的事，通常也很难提起兴趣。刚开始因为新鲜感，我还觉得能接受，但越到后面，每次画画、赶作业都成了一种折磨。我画得慢，画得丑，更关键的是——我根本不会凭空创作，脑子里没有画面，只能到处找图来临摹。不过还是推荐这门课，喜欢画画的更是可以无脑冲～
