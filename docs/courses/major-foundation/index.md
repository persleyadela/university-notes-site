# 物理化学

## 课程简介

早有耳闻说这门课很难，出于自己高中没有选化学以及对考试的担心恐惧本人认真地去上了每一节课，虽然最后成绩并不是很好（80/3.6）但是尽力了也没什么遗憾了。我上的是2024-2025春夏学期4学分的，授课老师是姚加和王永涛老师（前者教的特别好！！会注意大家表情来适当调整上课节奏并且讲的超好；后者好像是一个新老师），有挺多次小测的，基本上看到助教老师来并且带一堆白纸就是要小测了，小测主要是选择题，考一些概念理解，也有简单的计算。（我的小测卷子和书一起出掉了，忘记把小测题扫描成电子版整理了）。

个人最大的体会就是，这就是一门化学课，课上认真听，认真做作业，考前认真做历年卷还是都能跟上的。然后自己其实也在看b站上面彭笑刚老师的授课视频，但是好像是作为化学系专业课的，讲的好像更深更难一点，不过终究对帮助理解是有用的。
