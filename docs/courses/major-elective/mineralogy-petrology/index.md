# 矿物岩石学

## 课程简介

本人上的是2025-2026秋冬学期的，授课老师是刘佳、顾笑龑、邹东雅老师（分别教沉积岩、火成岩、变质岩部分），成绩92/4.8。这门课有意思的地方在可以看漂亮的岩石薄片，但是随之一起来的是要手写实验报告，描述看到的并且做分析。考试（占50%）由两部分组成——期末闭卷笔试+岩石薄片考试。平时分占另外的50%，主要是实验报告和作业。

可能要记忆的比较多，比如变质相这些。整体难度并不是特别大，稍微难一点的可能是薄片鉴定考试，但老师会从平时看的选出几种然后告知我们，框定完范围其实也就不难判断了。
