# 国土空间规划

## 课程简介

本人上的是2025-2026春学期张兴平老师的（90/4.5），上课的时候发现选的主要是地信的同学，然后总共点了2次名，平时会有两次写论文作业（关系是递进的，就是第一次作业是为第二次铺垫的），老师要求字数不要太多（好像是3还是4千字以内）；最后一次课是个人汇报，选一个自己感兴趣的课程相关的方向简单讲2-3min。

自己选这门课主要是为了凑选修课学分，可能是不太感兴趣其实很不好意思的说上课完全没咋听，最后考试是开卷考，大部分也能在ppt上找到（不得不提感觉ppt逻辑其实并没有特别顺溜清晰，可以考前自己理一遍），我考试的时候带了自己理的资料打印出来然后还有全部的ppt。
