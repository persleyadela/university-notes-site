# 实验地球物理

## 课程简介

本人上的是2025-2026春夏学期王帮兵老师的（93/4.8）。这门课前面是介绍一些基本原理之类的，后面大部分课程主要都是老师带着安装相关软件，然后进行数据处理。王老师很负责任，课上会考虑大家实践进度，就是一步一步教的那种，资料中有老师自己做的操作手册，有问题随时举手老师会很耐心地教。这门课我愿称之为浅地表地球物理“的兄弟课；课程中间会有2-3次到地科院大楼实践操作仪器的，这样就可以得到自己的一手数据（以班级为单位，大家一起布设装置）；课程最后也是个人汇报+课程报告。对于汇报老师要求有自己的思考，最好是把我们课上学到的数据处理或者一些地球物理简单建模与地质实际应用结合，即具有现实地质意义。

感觉其实这门课教了挺多实际操作的，最后汇报主题的选择空间也很大，适合有想法的人大展身手的那种。而且王老师人还是挺好的，会语重心长地引导然后鼓励做的好的点，比如说对于汇报老师就是说也是一次展示的机会，自己做的东西自己讲，也是为毕设答辩的小练习；反正整体来说挺好的一门课，唯一缺点可能就是操作软件处理数据过程中确实会遇到各种各样的新问题，可能有时候处理起来有点麻烦。毕竟大部分都是第一次安装并且使用这些软件，万事开头难这一块。
