# 浅地表地球物理

我上的是2025-2026春夏学期赵文轲老师的（90/4.5），平时老师ppt基本上是英文的，不过讲课是中文的，老师说在ai兴起之前都是让学生自己翻译英文的专业词汇和文献，现在自己反思教学方式是不是要改革；本来还担心作为地球物理的课程会不会太难，不过老师人很好，他的上课理念就是激发学生兴趣点，主要是介绍性质的上课（介绍地球物理方法，例如直流电法探测、电磁法、重磁、探地雷达、地震、高密度电法ERT等），建议和“实验地球物理”这门课一起搭配食用，自己上下来的感觉是两门课一个讲原理方法应用另一个主要是实操，相得益彰啊。

赵老师上课会随机点人翻译英语词汇（翻译不出来也没事，不过让翻译的词基本上是主要的重要的核心专业词汇），其实感觉还是很有用的，就像老师说的，以后在看相关文献至少不会太陌生。平时没作业，最后的课上会安排个人汇报，每个人15-20min中文汇报即可，选自己感兴趣的并且是浅地表相关的领域汇报，可以是介绍方法原理或者应用，也可以是自己的相关领域的研究。并且要交课程报告（我当时选题是“电阻率层析成像在滑坡含水监测中的研究进展”）。老师比较看重自己的思考，秉持着字数多少没关系，只要是自己动笔写，用自己的科技语言就好，也是想要让我们的科研水平得到锻炼的一种方式。

课程中间有一次去东4机房做实验，然后有几次（大概两次？）是去地科院大楼做实验。
