# 体育类

本人大学三年上过一下体育课：

排球（初级班），2023-2024秋冬，黄文婷老师，93/4.8；

跆拳道，2023-2024春夏，高月娥老师，92/4.8；

五人制足球，2024-2025秋冬，孙冠荣老师，100/5.0；

网球（初级），2024-2025春夏，楼兰萍老师，95/5.0；

羽毛球（中级），2025-2026秋冬，郑其适老师，96/5.0；

英式橄榄球（初级），2025-2026春夏，钱锋老师，91/4.5。

想说的是——老师们人！都！很！好！！🥰🥰🥰

唯一可能需要提醒的是体育课分数有竞赛加分，只要参加就有2分加到总分里面，大一上的时候觉得太麻烦就啥都没参加，结果就是差这两分就5.0了😭，感觉还是有些可惜的。另一个点就是，大家一定要相信自己相信老师，一开始选跆拳道、网球、橄榄球这些从来没接触过的运动的时候其实有些担心的，但是上了之后才发现并没有想象中那么难（除了网球一开始真的完全打不起来），而且老师比学生更怕挂科这事；基本上全勤，然后体测稍微练一练，应该都没问题的！

然后就是夏天上课太热了，记得橄榄球上课的时候经常烈日当空下我们打比赛，不过大部分时候老师其实挺好的，会让我们在阴凉的地方站着拉伸之类的；然后秋冬上课可能出完汗容易着凉，其他没有想说的了，enjoy the game，guys！
