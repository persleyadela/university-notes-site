# 大学物理（甲）I

## 课程简介

我上的是王从健老师2023-2024春夏学期的课。老师讲得很好，不过就是喜欢随机且竞速的小测而且次数好像还不是很少，不过小测是开卷，可以翻书翻笔记。我印象中大概流程是：让写完的同学举手，他看差不多就收卷。所以每次小测其实都挺紧张的——一方面是小测前的紧张，因为不知道这次课会不会测，而且有时候老师上完当天要讲的内容，就零帧起手开始发小测卷子了；另一方面是小测时的紧张，心脏突突突地跳，怕自己写慢了下一秒就要收卷。就讲课而言，老师真心教得很好！PPT从知识点到例题，再到结合课本习题，特别清楚，一步步递进。

老师在一开始上课就让我们把高中学的物理忘掉。其实后知后觉才发现老师说得真的很对。原因之一是，高中时我就针对课本上一些我不理解的知识点提出过质疑，当时高中物理老师跟我说：“其实等你上了大学就会发现，高中学的很多内容都是把复杂模型或计算过程简单化了。”所以高中一些知识点其实并不严谨（大概是这个意思，原话记不清了）。原因之二是，自己因为自以为有高中“扎实”的物理基础，学习时比较“骄傲”，觉得听上去都听得懂就掉以轻心了。所以坦诚地说，我的大物甲I成绩并不高，甚至可以说比较低了。也算是分享前车之鉴与血泪教训吧😭。
