# 大学物理（甲）II

##课程简介

我上的是李宏年/刘才明老师2024-2025秋冬学期的，印象中一直都是前者在教，后者可能代过两次课。

李宏年老师小测也不喜欢提前告知，可能这样就兼具小测与点名的性质了吧，一举两得。小测是闭卷，老师比较注重纪律保证公平。上课过程中有时候讲着讲着老师喜欢发表一些自己的观点（大概可能是对一些时政事情例如伊朗美国之类的），其实现在回想起来还蛮有意思的。
