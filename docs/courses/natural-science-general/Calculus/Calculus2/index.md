# 微积分（甲）II

## 课程简介

我上的是2023-2024春夏学期毕惟红老师的课，跟I差不多，也是每周三次课，两次是老师教学一次是习题课助教老师讲作业并且收作业。有期中期末考试。感觉整体来说比I难多了，接触的东西对我来说比较抽象。但是毕老师上课上的很好，推荐选她的微积分——上课的时候有自己的板书，就是自己一边在电脑还是平板上面写一边教，逻辑很清楚，并且我记得在钉钉群也会发一些资料帮助学习，例如笔记里面截图的一些有BWH水印的都是老师资料上面的内容。
