# 大学物理实验

## 课程简介

我是2024-2025秋冬学期上的这门课，具体选了哪些实验有些忘了，印象里面除了分光计的那个比较费眼睛以及麻烦之外其他实验都还挺有意思的。

一门实验课，老师一般都会仔细教怎么操作；由于选课网站经常抽风建议选课完确定下来后记得截图（方便看每周上课的教室信息，也建议提前去，因为东四真的容易找不到教室，后面自己去东四上专业课的时候经常可以看到有好多眼神迷茫的学弟学妹在找教室然后也有问路的）；我们那时候是每次实验前要根据书本写预习的部分（大概就是除了实验结果的其他内容），做完实验后完成报告，听说现在都是电子版实验报告了，听上去好爽啊，我还记得手写这个都快给我写出腱鞘炎了。得分的话我记得自己大部分实验报告都是九十多分，好像也有八十几的。

个人建议的话，少选光学的实验，太费劲了，大部分的就是慢且难操作。然后如果抛开实验报告不谈，做这些实验其实都还蛮好玩的，记得初高中那会儿听说有实验课就会特别激动开心。

然后最后还有一个理论考试，这方面cc98上面有很多前辈都整理了经验帖。
