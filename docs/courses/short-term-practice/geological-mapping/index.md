# 地质填图实习

## 实习概况

本次地质填图实习于 **2025年7月2日—7月21日** 在安徽省巢湖北部山区开展，主要工作区位于凤凰山及邻近地区，总时长20天。带队老师为陈宁华、邓洪旦老师。

与地质认知实习相比，本次课程更强调独立开展野外地质工作的能力。实习内容不再局限于认识岩石、地层和构造现象，而是进一步要求将野外观察、产状测量、地层划分、构造分析和地质制图等工作结合起来，最终形成对整个实习区区域地质特征的综合认识。

生活方面，这次全程都在实习基地，所以在住宿上比地质认知实习方便多了，不过也是需要带插排、吹风机、洗浴用品等，我当时自己还带了床被单以及枕套等，整体住的还是挺好的；饮食方面，饭菜也是好吃的，老师和我们一起吃食堂，一般出上午的半天野外然后回来干饭，下午整理白天的工作，晚上汇报；并且小组是每两天一次汇报（例如今天是135组汇报，那第二天就是246）。


## 主要工作内容

本次实习主要完成了以下工作：

- 野外踏勘与路线地质调查
- 地质观察点记录与地层界线追索
- 实测地层剖面及原始资料整理
- 岩性、地层与构造现象识别
- 地质产状测量与野簿记录
- 1:50000 地质图编制
- 综合地层柱状图绘制
- 实测地质剖面图绘制
- 室内资料整理与实习报告撰写

## 主要成果

本次实习最终完成了巢湖北部凤凰山一带约 **12 km²** 范围的地质填图，并整理形成了综合地质图、综合地层柱状图、实测地质剖面及相关野外原始资料。
