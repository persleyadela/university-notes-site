**支持向量机SVM的核心思想是什么？在线性可分和非线性不可分情况下分别如何处理？** SVM是一种监督学习分类方法，核心思想是在特征空间中寻找一个最优分类超平面，使两类样本之间的间隔最大，从而提高模型的泛化能力 / 真正决定分类边界的是离超平面最近的少数样本，这些样本称为支持向量 / 在线性可分情况下，SVM直接寻找最大间隔超平面，把两类样本分开 / 在线性不可分或非线性可分情况下，可以引入软间隔，允许少量样本分类错误，并用惩罚参数控制错误程度；也可以使用核函数，如RBF核、多项式核，把原始数据映射到更高维空间，使其在高维空间中更容易线性分开。\| **卷积神经网络CNN的基本结构、原理和特点是什么？举出地球科学中的典型应用。** CNN主要由输入层、卷积层、激活函数、池化层、全连接层和输出层组成 / 卷积层通过卷积核提取局部空间特征，激活函数引入非线性，池化层压缩特征并增强平移不变性，全连接层用于综合特征并完成分类或回归 / CNN的特点是局部连接、权值共享、层级特征提取和较强的空间特征学习能力 / 在地球科学中可用于遥感影像土地利用分类、云和降水识别、滑坡或洪水灾害识别、道路和建筑物提取、雷达回波外推等。\| **在数据驱动应用中，只有100个独立样本，建模时应该如何使用样本？** 100个样本属于小样本，不能简单把数据全部拿来训练后直接评价，否则容易高估模型效果 / 可以采用训练集、验证集、测试集划分，例如70%训练、15%验证、15%测试，但样本较少时更推荐使用K折交叉验证，如五折交叉验证 / 建模时要避免数据泄漏，标准化、特征选择、缺失值填补等操作应只在训练集上拟合，再应用到验证集或测试集 / 如果样本有类别，应采用分层抽样；如果有空间或时间相关性，应按空间块或时间段划分，避免相邻样本同时出现在训练和测试中 / 最后用交叉验证选择模型和超参数，再在保留测试集上评价泛化能力。\| **五折交叉验证的原理、特点、优势是什么？得到的模型如何应用？** 五折交叉验证是把数据平均分成5份，每次取其中1份作为验证集，其余4份作为训练集，重复5次，使每一份都被验证一次 / 最后取5次评价指标的平均值作为模型性能估计 / 优点是能充分利用有限样本，比单次划分更稳定，也能降低偶然划分带来的偏差 / 它常用于模型选择和超参数调优 / 实际应用时，不是直接使用五个模型中的某一个，而是先根据交叉验证结果确定最佳模型类型和参数，再用全部训练数据重新训练最终模型，最后应用到独立测试集或新样本上。\| **模型选型、模型评价、模型优化的功能和目标是什么？各举一个例子。** 模型选型是选择适合任务和数据特点的模型类型，目标是找到合适的表达能力，例如在线性回归、随机森林、SVM、神经网络之间进行比较 / 模型评价是用客观指标判断模型好坏，目标是估计模型在未知数据上的泛化能力，例如回归任务用R²、MSE、RMSE，分类任务用准确率、召回率、F1值 / 模型优化是调整模型参数或超参数，使损失函数降低、预测效果提高，例如用梯度下降优化神经网络权重，用网格搜索选择SVM的核函数和惩罚参数C。\| **回归模型中的欠拟合和过拟合是什么？分别有什么问题？如何改善？** 欠拟合是模型太简单，既不能很好拟合训练集，也不能很好预测新数据，表现为训练误差和测试误差都较大，本质是高偏差问题 / 欠拟合可能是特征不足、模型过于简单、训练不充分或正则化过强导致的，可通过增加特征、使用更复杂模型、降低正则化强度或延长训练来改善 / 过拟合是模型过度记住训练数据中的噪声和偶然特征，训练集效果很好但测试集效果差，本质是高方差问题 / 过拟合通常由样本少、模型太复杂、噪声大或特征太多导致，可通过增加数据、交叉验证、正则化、特征选择、早停、Dropout或简化模型来改善。\| **大气是混沌的，为什么气候仍具有可预测性？** 天气和气候的可预测性来源不同 / 天气预报主要是初值问题，受大气混沌性影响很大，初始条件中的微小误差会随时间快速放大，因此天气的确定性预报存在上限 / 气候预测更关注多年平均状态、概率分布和慢变化趋势，不是预测某一天的具体天气 / 气候系统受海洋、陆面、冰雪、太阳辐射、人类活动等边界强迫影响，这些外部因子变化相对较慢，如果边界强迫较强且稳定，就会给气候系统提供一定可预测信号 / 因此，气候可预测性主要来自慢变边界条件和统计规律，而不是对每一天天气的精确预测。\| **如果观测精度不断提高、资料质量不断提升、数值模式不断完善，预报有效时长是否可以无限增加？** 不能无限增加 / 观测和模式进步确实可以提高预报技巧，延长一定预报时效，但大气系统具有混沌性，初始误差会随时间增长，最终导致确定性天气预报失效 / 数值模式也不可能完全表达所有尺度的物理过程，参数化方案、边界条件和计算分辨率都会带来误差 / 因此天气预报存在理论和实际上限，通常中短期天气预报不能无限延长 / 但气候预测可以在更长时间尺度上预测统计特征、概率趋势或异常信号，这与逐日天气预报不是同一类问题。

**ConvLSTM是什么？与LSTM相比结构有什么不同？有什么优势？** ConvLSTM是在LSTM基础上引入卷积运算的时空序列模型 / 普通LSTM用全连接矩阵处理输入和隐藏状态，适合一维时间序列，但会破坏图像或格点数据的空间结构 / ConvLSTM把输入门、遗忘门、输出门和候选记忆中的矩阵乘法替换为卷积操作，使隐藏状态和细胞状态保持二维或三维空间结构 / 它既能学习时间依赖，又能保留局部空间相关性 / 优势是参数量相对更少、适合处理雷达回波、气象格点、遥感影像序列、海温场等时空数据，在短临降水预测、气候场演变预测等任务中很有用。\| **LSTM的结构是什么？它如何解决RNN的记忆问题？** LSTM是一种改进的循环神经网络，核心结构包括细胞状态、遗忘门、输入门、输出门和候选记忆 / 遗忘门决定保留多少旧信息，输入门决定写入多少新信息，输出门决定当前隐藏状态输出多少记忆信息 / 普通RNN在长序列反向传播时容易出现梯度消失，导致远距离信息难以保留 / LSTM通过细胞状态提供较稳定的信息传递通道，并用门控机制控制信息的保留、更新和输出，因此能更好学习长期依赖关系 / 但LSTM参数较多，训练成本比普通RNN高。\| **解释梯度消失和梯度爆炸，原因是什么？解决途径有哪些？** 梯度消失是反向传播过程中梯度越来越小，前面层或早期时间步几乎得不到有效更新；梯度爆炸是梯度越来越大，导致参数剧烈震荡甚至出现数值溢出 / 在RNN中，这主要来自循环权重矩阵在时间维度上反复连乘，如果特征值或导数长期小于1，梯度会衰减；如果长期大于1，梯度会爆炸 / 梯度消失会使模型难以学习长距离依赖，梯度爆炸会使训练不稳定 / 解决方法包括使用LSTM或GRU门控结构、梯度裁剪、残差连接或跳跃连接、层归一化、合理初始化参数、使用ReLU类激活函数、正则化、缩短反向传播长度等。\| **RNN、LSTM和GRU有什么关系？** RNN是处理序列数据的基础循环神经网络，隐藏状态会沿时间步传递，适合时间序列、文本、气象序列等任务 / LSTM是在RNN基础上加入输入门、遗忘门、输出门和细胞状态，主要解决长距离依赖和梯度消失问题 / GRU是比LSTM更简化的门控循环单元，通常只有更新门和重置门，没有单独的细胞状态，参数更少、训练更快 / 三者都用于序列建模，但普通RNN更简单，LSTM记忆能力更强，GRU在效果和计算成本之间更折中。\| **监督学习和无监督学习有什么区别？** 监督学习的数据带有标签，目标是学习输入和输出之间的映射关系，常用于分类和回归任务，例如用气象因子预测降水量、用遥感影像分类土地覆盖 / 无监督学习的数据没有标签，目标是从数据本身发现结构和规律，常用于聚类、降维和异常检测，例如用K-means划分地球化学异常区，或用PCA压缩高维环境变量 / 简单说，监督学习是“有答案地学习”，无监督学习是“从数据中自己找规律”。\| **K-means聚类的基本原理、步骤、优缺点是什么？** K-means是一种无监督聚类方法，目标是把样本按特征相似性分成K个簇，并使簇内样本尽量相似、簇间样本尽量不同 / 步骤是先随机初始化K个聚类中心，再根据欧氏距离把每个样本分配给最近的中心，然后计算每个簇的新均值作为新中心，重复分配和更新，直到聚类结果稳定或达到迭代次数 / 优点是原理简单、计算速度快、容易实现，适合大规模数据初步分组 / 缺点是需要预先指定K值，对初始中心敏感，对量纲敏感，倾向于发现球形簇，对异常值和非凸形状数据效果较差 / 可用多次初始化、数据标准化、K-means++、手肘法和轮廓系数改善结果。\| **K-means中如何选择合适的K值？手肘法和轮廓系数有什么区别？** K值决定聚类个数，对结果影响很大 / 手肘法观察簇内误差平方和SSE随K增加的变化，K越大SSE通常越小，但当SSE下降幅度明显变缓时，曲线拐点对应的K常被认为较合适 / 轮廓系数同时考虑簇内凝聚度和簇间分离度，值越接近1说明样本更适合当前聚类，接近0说明处在簇边界，接近负值说明可能分错类 / 手肘法直观但有时拐点不明显，轮廓系数更综合但计算成本更高，实际中常结合专业背景一起判断。\| **空间轨迹数据的聚类分析可以获得什么信息？有什么作用？** 空间轨迹聚类可以把具有相似移动路径、出行时间或活动模式的轨迹分成不同类型 / 可以发现城市中的主要通勤走廊、热点区域、常见OD流向、拥堵传播路径、异常出行行为、功能区联系和人群活动节律 / 在城市交通中，它可用于交通规划、拥堵治理、公共交通线路优化、共享出行调度和异常事件检测 / 在地学和环境研究中，也可用于动物迁徙、海洋漂流轨迹、污染物扩散路径和灾害避险行为分析。\| **基于深度学习框架，如何对城市轨迹数据进行时空模式挖掘？可能挖掘出哪些时空模式？** 首先需要采集GPS轨迹、时间戳、速度、方向、道路网络、POI和天气等数据，并进行清洗、去噪、地图匹配和时间空间离散化 / 然后可以把城市划分为网格，用CNN或ConvLSTM提取空间分布和时间演化；也可以把道路网络建成图，用GNN学习路段之间的拓扑关系；对轨迹序列可用RNN、LSTM或Transformer学习长期时间依赖 / 可挖掘的模式包括早晚高峰通勤规律、城市功能区联系、交通拥堵传播、出行热点、异常轨迹、节假日出行变化、OD流量结构和不同人群活动模式。

**如何测量地球体系内液体的体积和质量？如果已知某种物质，想根据化学平衡计算另一种物质，用什么类别的机器学习方法？** 液体体积通常可通过空间范围乘以厚度或深度估算，例如湖泊面积乘水深、冰川面积乘厚度、海洋或地下水体积结合地形和水位资料计算 / 质量一般由体积乘以密度得到，也可以通过重力卫星、雷达高度计、遥感反演和现场观测估计水体或冰体质量变化 / 如果已知一种物质或若干输入变量，想预测另一种物质的浓度、含量或连续数值，通常属于监督学习中的回归问题 / 如果化学平衡关系明确，可以结合物理化学约束建立回归模型，如多元线性回归、稀疏回归、非线性回归或物理约束机器学习模型。\| **列举三种空间回归方法，并说明特点和优缺点。** 地理加权回归GWR允许回归系数随空间位置变化，适合研究空间异质性，优点是能反映不同地区影响因素差异，缺点是带宽选择敏感、容易受局部样本和多重共线性影响 / 空间滞后模型SLM在模型中加入邻近地区因变量的影响，适合存在空间溢出效应的情形，优点是能描述邻近地区相互影响，缺点是模型解释和估计比普通回归复杂 / 空间误差模型SEM把空间相关性放在误差项中，适合遗漏变量或误差存在空间自相关的情况，优点是能修正空间相关导致的估计偏差，缺点是对空间权重矩阵依赖较强，直接解释性不如普通回归。\| **地球科学发展前沿的趋势是什么？** 地球科学正在从单一观测和经验解释走向多源观测、数据驱动和物理机制融合 / 重要趋势包括卫星、无人机、传感器和深海深地观测形成多源大数据体系，高性能计算支持高分辨率数值模拟，机器学习和深度学习用于复杂模式识别和预测 / 同时，纯数据驱动方法需要与物理规律结合，因此物理信息神经网络、可解释AI、数字孪生地球、地球系统模拟、多圈层耦合和智能体辅助科研是重要方向 / 总体上是从“看现象”走向“数据—模型—机制—预测”一体化。\| **利用机器学习进行气候预测存在哪些问题？** 气候系统是多圈层耦合的复杂系统，具有非线性、多尺度、混沌性和强物理约束，机器学习容易只学到统计相关而不一定学到物理因果 / 气候观测记录相对有限，高质量样本少，极端事件样本更少，导致深度模型容易过拟合 / 多源数据存在尺度、分辨率、误差和缺测差异，数据融合困难 / 气候背景会随全球变暖发生变化，训练集和未来预测情景可能分布不一致 / 黑箱模型可解释性不足，不确定性量化困难，难以保证守恒规律和物理一致性 / 因此机器学习在气候预测中需要结合物理约束、数值模式、因果分析和可解释方法。\| **数值预报和机器学习预报有什么区别？** 数值预报主要基于大气运动、热力学和流体力学方程，在给定初值和边界条件后，通过离散化和计算机迭代求解未来大气状态，属于“数据 + 方程求解” / 机器学习预报主要从历史观测、再分析资料或模式输出中学习输入和输出之间的统计映射，属于“数据驱动建模” / 数值预报物理基础强、可解释性较好，但计算成本高、模式误差和参数化误差不可避免 / 机器学习速度快、适合复杂非线性映射和后处理任务，但容易缺乏物理一致性和可解释性 / 未来趋势不是简单替代，而是物理模式与机器学习融合。\| **天气和气候有什么区别？** 天气是某地短时间内大气状态和现象的综合表现，例如几分钟到几天内的气温、降水、风、云等 / 气候是某地区多年平均天气状态及其变化特征，通常用30年左右的时间尺度描述 / 天气变化快、随机性强，气候变化慢、反映统计特征 / 天气预报更偏初值问题，气候预测更偏边界强迫问题 / 天气可以看作气候背景场上的短期扰动，气候则是对大量天气过程的统计概括。\| **为什么需要数据清洗？脏数据有哪些类型？如何处理？** 原始地学数据往往不能直接输入模型，因为遥感影像可能有云遮挡、条带噪声，时间序列可能有断点、尖峰和缺测，调查数据也可能重复或录入错误 / 常见脏数据包括缺失值、异常值和重复值 / 缺失值可用删除、均值或中位数填充、前向后向填充、插值、模型插补和多重插补处理 / 异常值需要先判断是噪声还是有意义信号，噪声可剔除或修正，有价值的异常可能代表极端事件或地质异常 / 重复值可删除，也可根据可靠性合并。\| **缺失数据有哪些类型？处理时应注意什么？** 缺失数据可分为完全随机缺失MCAR、随机缺失MAR和非随机缺失MNAR / MCAR指缺失与任何变量无关，直接删除带来的偏差较小 / MAR指缺失概率与已观测变量有关，可利用其他变量进行插补 / MNAR指缺失与缺失值本身有关，例如极端值更容易缺测，这种情况最复杂，简单填补可能产生系统偏差 / 处理缺失值时要根据缺失机制、样本量和变量重要性选择方法，不能机械地全部均值填充。\| **异常值检测有哪些常见方法？** Z-Score方法用样本均值和标准差判断离群程度，适合近似正态分布的数据，但均值和标准差本身容易受异常值影响 / IQR四分位距法用Q1、Q3和四分位距判断异常区间，不要求正态分布，比较稳健，但主要适合单变量 / kNN异常检测用样本到第k个近邻的距离作为异常分数，距离越大越可能异常 / LOF本地异常因子比较样本自身密度与邻域密度，适合发现局部离群点 / 地学中异常值不一定都是错误，也可能是极端气候事件、矿化异常或灾害信号，所以应结合背景判断。

**数据编码有哪些常用方法？如何选择？** 数据编码是把非数值信息转化为模型可计算的数值特征 / 标签编码适合有自然顺序的类别，例如风化程度轻度、中度、重度，如果类别没有顺序就不能随意编码成1、2、3，否则会制造虚假的大小关系 / 独热编码适合少量、平等的名义类别，例如岩性类别、土地覆盖类型，但类别太多会造成维度灾难 / 频率编码用类别出现频率表示类别，适合高基数类别 / 目标编码用类别对应目标变量的统计值表示类别，能压缩维度，但必须防止数据泄漏 / 选择编码方法要看类别是否有顺序、类别数量大小以及任务目标。\| **为什么需要归一化或标准化？常见方法有哪些？** 不同特征量纲差异很大会影响模型训练，例如主量元素和微量元素数量级差异很大，直接输入模型会使大数值特征主导结果 / 归一化和标准化可以把不同变量放到可比较尺度上，提高模型稳定性和收敛速度 / Min-Max归一化把数据缩放到固定范围，适合有明确上下界的数据 / Z-score标准化把数据变成均值为0、标准差为1，适合近似正态分布的数据 / RobustScaler使用中位数和四分位距，对异常值更稳健 / 对数变换适合长尾分布和跨数量级数据 / 成分数据还要考虑闭合效应，不能只做普通标准化。\| **什么是闭合效应？为什么地球化学成分数据常用CLR变换？** 闭合效应是指成分数据各组分总和被强制约束为常数，例如100%或10⁶ ppm / 当某一组分增加时，其他组分即使绝对量没有变化，相对比例也会被动下降，从而产生虚假的相关关系 / 中心对数比变换CLR把每个组分与该样本所有组分的几何平均值作比值，再取对数，可以把“绝对含量比较”转化为“相对比例结构比较” / 这样能减弱闭合约束造成的伪相关，更适合地球化学、岩石成分和环境化学数据建模。\| **什么是维度灾难？为什么需要特征降维？** 维度灾难是指随着特征维度增加，样本在特征空间中变得极度稀疏，模型需要更多样本才能可靠学习规律 / 维度过高还会带来计算成本增加、噪声特征增多和过拟合风险 / 地学数据中常有冗余特征、无关特征和强相关特征，例如年龄和出生年份、相邻波段遥感数据、多个相关气候变量 / 降维可以压缩信息、减少噪声、降低计算量并提高模型泛化能力 / 常见方法包括PCA、LDA、特征选择和嵌入表示。\| **PCA和LDA有什么区别？** PCA是无监督降维方法，不需要标签，核心思想是寻找数据方差最大的投影方向，使降维后尽量保留原始数据的信息 / PCA适合压缩高维变量、去除冗余和可视化，例如多波段遥感数据或多元素地球化学数据降维 / LDA是监督降维方法，需要类别标签，核心思想是让类间距离尽量大、类内方差尽量小，从而增强类别可分性 / PCA关注“保留整体变化信息”，LDA关注“更好地区分类别” / 所以做聚类或无标签探索常用PCA，做分类前的特征压缩可考虑LDA。\| **欧氏距离和马氏距离有什么区别？** 欧氏距离是普通直线距离，直观简单，对每个维度一视同仁，但容易受量纲影响，也没有考虑特征之间的相关性 / 马氏距离考虑协方差结构，会根据数据分布和变量相关性调整距离度量 / 如果两个特征强相关，马氏距离不会把相关方向上的差异简单重复计算 / 在地学数据中，不同环境因子、地球化学元素或气候变量常存在相关性，所以马氏距离比欧氏距离更适合某些异常检测和多变量相似性分析 / 但马氏距离需要可靠估计协方差矩阵，对样本量和异常值较敏感。\| **地学数据有哪些常见容器？它们分别适合什么数据？**地学数据常见容器包括文本数据、数据表、栅格数据和矢量数据 / 文本数据如txt、json、xml，适合野外记录、日志和描述性资料 / 数据表如csv、xlsx，适合采样点、观测记录、钻孔数据和地震事件表 / 栅格数据如tif、hdf、nc，适合遥感影像、DEM、气温降水格点和海温场 / 矢量数据如shp、geojson、gpkg，适合河流、道路、断层、行政区、点位和面状地理要素 / 不同容器对应不同的数据结构，选择模型时也要考虑其是静态属性、空间结构还是时间序列。\| **地学数据从原始数据到AI模型一般经历哪些步骤？** 一般流程是原始数据获取、数据读入与解析、数据清洗、类型转换、编码、归一化或标准化、特征构建、降维或特征选择、数据集划分、模型训练、模型评价和解释 / 原始数据往往形式复杂，不能直接输入模型 / 经过预处理后，文本、表格、栅格、矢量和时间序列数据需要被转化为模型可理解的结构化特征 / 最后根据任务选择回归、分类、聚类、序列预测、图学习或生成模型。

**线性回归和逻辑回归分别解决什么问题？** 线性回归用于预测连续数值，核心是用一条直线或超平面拟合自变量与因变量之间的关系，例如根据年份预测二氧化碳浓度 / 它通常通过最小化残差平方和来求解参数 / 逻辑回归主要用于二分类问题，输出的是某事件发生的概率，例如是否发生滑坡、是否为某类土地覆盖、邮件是否垃圾邮件 / 虽然名字中有“回归”，但逻辑回归本质上常用于分类。\| **最小二乘法和牛顿法有什么区别？** 最小二乘法的核心是让观测值和拟合值之间的误差平方和最小，在线性回归中可以通过令偏导数为零得到解析解，适合简单线性模型和参数线性的模型 / 牛顿法是一种数值优化方法，通过一阶导数和二阶导数迭代逼近极值点，适合更复杂的目标函数 / 最小二乘法一步到位、结果精确，但适用范围相对有限 / 牛顿法收敛速度快，但需要初始值和二阶导数，可能陷入局部极小值，单次计算成本较高。\| **回归模型常用评价指标有哪些？** R²决定系数表示模型解释因变量变异的比例，越接近1说明拟合越好，但模型形式错误时也可能出现负值 / MSE均方误差是预测误差平方的平均值，对大误差敏感 / RMSE是MSE开平方，单位与原始变量一致，更容易解释 / MAE是绝对误差平均值，对异常值不如MSE敏感 / 评价模型时不能只看训练集指标，还要看测试集或交叉验证指标，防止过拟合。\| **图神经网络GNN是什么？为什么地学中需要GNN？** GNN是一类基于图结构数据的深度学习方法，用于提取节点、边和整体图的特征模式 / 图由节点、边和特征组成，邻接矩阵描述节点之间的连接关系 / 许多地学对象不是规则网格，而是非欧式结构，例如交通路网、河网、断层网络、监测站点网络、城市联系网络和地震事件关联网络 / CNN适合规则网格，RNN适合序列，而GNN适合邻居数量不固定、拓扑关系复杂的数据 / GNN通过消息传递机制聚合邻居信息并更新节点表示，可用于节点分类、图分类、链路预测、空间关系建模和时空预测。\| **GNN中的消息传递机制是什么？** 消息传递一般包括聚合和更新两个步骤 / 聚合是每个节点从邻居节点收集信息，例如对邻居特征进行加权求和、平均或注意力加权 / 更新是节点把邻居信息与自身特征结合，得到新的隐藏表示 / 多层GNN可以扩大感受野，使节点逐渐获得更远邻域的信息 / 这种机制类似“近朱者赤，近墨者黑”，节点表示不仅由自身属性决定，也由周围邻居和图结构共同塑造。\| **人工智能可解释性为什么重要？** 很多高性能模型如深度神经网络、随机森林和SVM常被视为黑盒模型，预测结果不容易解释 / 可解释性有助于发现模型是否学到了错误线索，例如图像分类模型可能关注背景而不是目标本身 / 在医疗、司法、灾害预警和地球科学决策中，模型不仅要准确，还要可靠、公平、透明 / 可解释性还能帮助科学发现，理解哪些变量、区域或时间段对预测最重要 / 因此可解释AI不仅是让人“看懂模型”，也是提高模型可信度和科学价值的重要手段。\| **白盒模型和黑盒模型有什么区别？** 白盒模型结构较简单，决策过程相对透明，例如决策树、线性回归、分类规则等 / 黑盒模型结构复杂、参数多，虽然预测能力强，但内部决策机制难以直接理解，例如深度神经网络、随机森林、SVM等 / 一般来说，模型性能和可解释性之间常存在一定权衡 / 对高风险任务，不能只追求精度，还要关注模型是否能解释、是否稳定、是否符合物理和专业知识。\| **SHAP是什么？基本思想是什么？** SHAP来自博弈论中的Shapley Value，用来解释每个特征对模型预测结果的贡献 / 它把一次预测看作多个特征共同合作得到的结果，通过计算某个特征加入不同特征组合时带来的边际贡献，并对所有可能组合取平均，得到该特征的贡献值 / SHAP的优点是解释比较公平、可用于局部解释和全局解释 / 缺点是精确计算需要遍历所有特征组合，计算复杂度很高，通常需要KernelSHAP、TreeSHAP、DeepSHAP等近似或专门方法。\| **Saliency Map和CAM主要解释什么？** Saliency Map主要用于解释图像模型，思想是计算输出类别对输入像素的梯度，梯度越大说明该像素对预测结果越敏感 / 它可以显示模型判断时关注图像的哪些区域 / CAM类激活映射利用CNN最后一层卷积特征图和分类权重，生成与类别相关的热力图，显示哪些空间区域推动了某一类别判断 / 在遥感、灾害识别和气象图像分析中，这些方法可以帮助判断模型是否关注了合理的地物、云团、灾害体或异常区域。

**物理信息神经网络PINN是什么？基本思想是什么？** PINN是一种把物理方程嵌入神经网络训练过程的模型 / 它不仅用观测数据约束模型输出，还把偏微分方程、边界条件和初始条件写入损失函数 / 总损失通常包括数据损失、物理方程残差损失和边界或初始条件损失 / PINN利用自动微分计算网络输出对空间和时间变量的导数，从而判断模型是否满足物理规律 / 它适合求解正问题、反问题和数据稀缺但物理规律明确的任务。\| **PINN的优势和局限是什么？** PINN的优势是能把物理规律作为约束，减少对大量标注数据的依赖，提高小样本场景下的泛化能力 / 它不一定需要复杂网格，能处理部分噪声数据和缺失数据，也适合参数反演、高维PDE和多物理场问题 / 在地学中可用于地震波传播、地下介质参数估计、流体运动、气候和地球系统模拟等 / 局限是训练过程可能不稳定，物理损失和数据损失之间权重难调，多尺度和高频问题难学，大规模问题计算成本高 / 所以PINN不是万能方法，更适合物理规律清楚、数据相对稀缺、任务规模可控的情形。\| **纯数据驱动方法在地学领域有什么局限？** 地球系统受到物理、化学、生物过程共同控制，具有非线性、多尺度和强耦合特点 / 纯数据驱动模型可能在训练数据范围内表现很好，但在极端事件、未来气候背景变化或样本分布变化时失效 / 它可能违背守恒定律、边界条件或已知物理机制 / 地学高质量观测数据往往稀疏、噪声多、尺度不一致，模型容易过拟合 / 因此地学AI不能只依赖黑箱拟合，需要融合物理约束、专业知识、可解释性和不确定性分析。\| **Transformer的核心思想是什么？** Transformer是一种基于注意力机制的深度学习架构，核心是用自注意力机制直接建模序列中任意两个元素之间的关系 / 注意力机制可以理解为Query、Key、Value的匹配过程，模型用Query去和Key计算相关性，再对Value加权求和得到新的表示 / 自注意力中Q、K、V来自同一序列，因此能捕捉序列内部的上下文关系 / 多头注意力让模型从多个角度学习不同关系 / Transformer还需要位置编码来补充词序或空间顺序信息 / 它相比RNN更容易并行计算，也更擅长捕捉长距离依赖。\| **Self-Attention和Cross-Attention有何区别？** Self-Attention的Q、K、V来自同一个序列，用于计算序列内部不同元素之间的关联，编码器和解码器中都可以使用 / Cross-Attention的Q来自一个序列，K和V来自另一个序列，用于建立两个序列之间的关联，典型出现在Transformer解码器中，例如机器翻译时让目标语言词元关注源语言句子 / 简单说，自注意力是“自己内部互相看”，交叉注意力是“一个序列去看另一个序列”。\| **Transformer中的Encoder和Decoder分别有什么作用？** Encoder负责把输入序列编码为包含上下文信息的表示，适合语义理解、分类、检索、特征提取等任务 / Decoder负责根据已有信息逐步生成目标序列，适合文本生成、翻译、摘要、对话等任务 / Encoder偏向表示学习，Decoder偏向生成 / BERT主要使用Encoder结构，擅长理解类任务；GPT主要使用Decoder结构，擅长生成类任务。\| **BERT和GPT有什么区别？** BERT是基于Transformer Encoder的双向语言模型，能同时利用左右上下文，常用于文本分类、阅读理解、语义匹配和信息抽取 / 它的典型预训练任务是掩码语言模型MLM和下一句预测NSP / GPT是基于Transformer Decoder的单向自回归语言模型，根据前文预测下一个Token，常用于文本生成、问答、对话和复杂任务规划 / 它的典型预训练目标是下一词预测NTP / 简单说，BERT更偏“理解”，GPT更偏“生成”。\| **大模型为什么需要微调？常见微调方式有哪些？** 预训练大模型通过海量数据学到通用语言和知识能力，但不一定会按照人的具体指令完成任务，也不一定适合某个专业场景 / 微调的目标是让模型适应特定任务、领域数据和人类偏好 / 监督微调SFT用高质量“指令—回答”数据训练模型，使模型从文本续写转向按要求回答 / RLHF通过人类偏好训练奖励模型，再用强化学习让模型输出更有用、更诚实、更安全的回答 / 参数高效微调如LoRA通常冻结大模型主体，只训练少量低秩适配参数，成本更低，适合专业领域迁移。\| **智能体Agent的概念是什么？有哪些核心模块？举一个生活例子。** 智能体是能够感知环境、理解目标、自主决策并采取行动的软件系统 / 它不是只回答一句话的大模型，而是能围绕目标进行规划、调用工具、利用记忆、根据反馈调整行动 / 核心模块通常包括大模型控制核心、感知输入、记忆模块、规划推理模块、工具调用模块、外部知识检索模块、执行模块和反馈反思模块 / 例如订午饭智能体会先感知时间和位置，记住用户最近吃过什么，规划配送范围，调用外卖工具比较餐馆，完成下单并通知用户 / 这体现了自治性、反应性、主动性和一定社会交互能力。\| **大语言模型本身有哪些缺陷，为什么需要智能体？** 大语言模型本身存在静态知识、信息孤岛、上下文窗口有限、缺乏环境交互能力和缺少持续反思能力等问题 / 它可能不知道最新信息，也不能天然访问外部数据库、网页、软件或真实环境 / 智能体通过记忆模块弥补上下文不足，通过RAG连接外部知识库，通过工具调用完成搜索、计算、文件处理和执行动作，通过任务规划和反馈机制完成复杂目标 / 因此智能体可以看作是在大模型基础上加入记忆、工具、规划和行动能力后的复杂系统。\| **RAG、Function Calling、CoT和ReAct分别解决什么问题？** RAG即检索增强生成，通过外部知识库、向量数据库或知识图谱为大模型补充最新或专业资料，减少幻觉和知识过时问题 / Function Calling让大模型按结构化格式调用工具，例如搜索、计算、读取文件、运行脚本和格式转换，使模型能从“说”走向“做” / CoT思维链通过中间推理步骤提高复杂推理能力，适合数学、逻辑和多步问题 / ReAct把Reasoning和Action结合起来，让模型在“思考—行动—观察”循环中边规划边执行，适合搜索、交互问答和工具使用任务。\| **AI可解释性、PINN和智能体在地球科学大数据中的意义分别是什么？** AI可解释性解决“模型为什么这样判断”的问题，有助于提高黑箱模型的可信度，并支持科学发现 / PINN解决“模型是否符合物理规律”的问题，把数据驱动和物理机制结合起来，适合地学中数据稀缺但方程明确的任务 / 智能体解决“模型如何完成复杂任务”的问题，通过记忆、检索、工具和规划把大模型变成能辅助科研和工作流执行的系统 / 三者共同反映地球科学AI的发展方向：不只是追求预测精度，还要追求可信、物理一致、可执行和可解释。
