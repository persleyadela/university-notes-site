# 地球科学大数据（2025-2026春夏学期）

## 课程简介

地球科学大数据主要介绍机器学习、深度学习及大数据分析方法在地球科学中的基本原理与应用。对地质学学生而言感觉大部分内容属于第一次接触，而地信的同学可能上过类似的课程会有些基础；然后是典型的“拼好课”，授课老师有张丰、苏程、孔鸣、贾晓静、Bryan Riel老师。每周都会在mo平台（https://mo.zju.edu.cn）上布置一些代码作业，涉及补全代码、调参数运行等，大部分其实都可以结合自己的AI来完成，其中有几个可能运行很慢，如果是那种调参数重复试验比较模型的性能，千万记得重开一个ipynb文件，要不然直接在原文件该的话结果会被覆盖（血泪教训），后面整理起来很费劲很无力。并且调用的是mo平台计算资源，可以生成py工程用gpu环境跑，速度会快些。然后代码的作业在mo平台上需要主动操作提交（不会因为到了截止日期自动提交，依旧血泪教训），作业分占比还挺高的。具体关于该课程也可以去查老师网站上面搜zf老师的评价看。

课程内容涵盖地学数据预处理、监督学习与无监督学习、回归与分类、模型评价与优化，以及 CNN、RNN、LSTM、ConvLSTM、GNN、Transformer 等常见深度学习模型，并进一步涉及可解释人工智能、物理信息神经网络（PINN）和智能体（Agent）等内容。并且强调将数据科学方法与具体地球科学问题结合，例如遥感影像分析、气候预测、冰冻圈与海洋数据反演、地震研究、空间轨迹分析以及地球化学数据处理等。

考试形式为半开卷，22级的学长学姐说他们是只允许带一张A4纸资料，我们23级的是允许三张（可手写可打印）。
