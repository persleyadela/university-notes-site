# 个人科研经历

浙江大学本科生科研训练网站：http://kyjs.zju.edu.cn/

本人于2025年3月至2026年5月参与SRTP项目“环青藏高原造山带隆升差异性”，开题答辩后该项目被认定为校级项目，最终顺利结题，评定等级为良好。然后联系导师是我们组助长负责的，通常导师就会帮忙选好一个适合给本科生做的项目小切口。所以不需要担心自己是不是没能力做好或者会不会太难坚持不下去。

我们小组共三人，每人负责一片区域的研究工作。然后我们组相对是比较独立的，每个人自己做自己的，现在反思下来感觉组内交流太少了，有点孤军奋战的味道了。我所做项目主要流程是：首先利用 ArcGIS 对研究区 DEM 和热年代学数据进行空间裁剪和整理，并将 AFT、ZFT、AHe、ZHe 等不同体系的数据统一转换为 GLIDE 所需的输入格式；之后根据研究区和参考文献设置先验剥蚀速率、空间相关长度、时间步长等参数，通过xshell连接学院计算平台，用 Linux 服务器运行 GLIDE 反演；最后利用 MATLAB 对结果进行后处理，得到不同时段的剥蚀速率和 Normalised Variance 空间分布。基于此，我编写了一份Glide操作手册，详细记录了每一步操作，力求将繁琐流程标准化，使他人能够据此复现运行结果。

刚接触项目时，其实对于我来说是有较大的难度的——许多科研软件不熟悉，代码难以理解，各参数的具体含义也常不清楚。好在师兄师姐们非常耐心，愿意悉心指导，老师也要求我们每人至少每两周汇报一次进展。回顾整个过程，确实是“万事开头难”——一旦跑通了第一遍流程，后续工作便主要是在此基础上优化结果以及对于结果进行地质解释。同时，我也意识到主动寻求帮助的重要性，师兄师姐通常很乐意提供支持，他们积累的经验对加快自己的科研进度起到了难以估量的作用（不要自己一个人死磕到底就对了）。



# 感悟

勇敢去尝试、去实践、跨出第一步，我觉得是最重要的。科研过程中确实会遇到许多问题和难关，但方法总比困难多。多向老师和师兄师姐请教，多问、多看、多学，事情总会朝着越来越好的方向发展。刚开始上手时可能会比较难熬，付出九分努力，可能只换来一分进展；但随着逐渐熟悉，后续会越来越顺利，出图结果也会更加规范、美观。自己得到正反馈之后也会越来越有自信。

当你焦虑的时候，不要胡思乱想，直接动手去做点什么，往往就不会那么害怕未来了。
